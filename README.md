# skills

| Skill | Description |
|---|---|
| [tools-ui-design](tools-ui-design/) | A design language for tool and desktop-app UIs, extracted from [magpie](https://github.com/yetone/magpie): principles, colors, themes (light, dark, tray panel, colorblind), typography, components, motion, the logo and app-icon style, and the marketing site. |
